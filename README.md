# Restaurante Lusitano Leiria 🍷🍽️

Website oficial e aplicação web para o **Restaurante Lusitano** (Estrada da Estação 89, Leiria).

## 🚀 Funcionalidades
- **Quadro Digital dos Pratos do Dia:** Ementa interativa por dia da semana (Segunda a Sábado) com sopas, peixe, carne grelhada no carvão, opções vegetarianas e sobremesas.
- **Simulador de Pedido de Take-Away:** Seleção rápida de pratos, doses e hora de levantamento, com geração automática de mensagem formatada para o WhatsApp do restaurante (`937 117 791`).
- **Especialidades da Casa:** Picanha e Maminha na brasa, Peixe fresco grelhado, Bacalhau com natas e Bitoques à Lusitano.
- **Integração com Instagram:** Destaque para o perfil `@restaurante_lusitano_leiria`.
- **Localização & Acessos:** Ligações diretas para Google Maps, Waze e chamadas telefónicas.

## 🛠️ Tecnologias
- **Next.js 15 (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React**
